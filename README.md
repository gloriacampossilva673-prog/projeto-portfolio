# Projeto - Portfólio

Página de Portfólio / Currículo Web de um desenvolvedor.

## Objetivo

Criar uma página HTML limpa, semântica e funcional, reproduzindo os tópicos e a organização do layout proposto.

## Requisitos Principais

### Cabeçalho e Navegação

* Título principal com o nome ou cargo do desenvolvedor.
* Menu de navegação com links para as seções:

  * Sobre
  * Projetos
  * Contato

### Seção "Sobre Mim"

* Foto de perfil com aproximadamente 150px de altura e 150px de largura.
* Texto de apresentação.
* Lista com as principais habilidades do desenvolvedor.

### Seção "Meus Projetos"

Tabela organizada contendo quatro colunas:

* Projeto
* Tecnologias
* Status
* Link

Os links dos projetos devem ser funcionais e direcionar para suas respectivas páginas.

### Seção "Entre em Contato"

Formulário envolvido por um `<fieldset>` com o título "Dados do Contato".

O formulário deve conter:

* Campo para Nome.
* Campo para Email.
* Menu suspenso `<select>` para seleção do Assunto.
* Área de texto `<textarea>` para Mensagem.
* Botão para envio do formulário.

### Rodapé

O rodapé deve conter:

* Direitos autorais utilizando o caractere especial `&copy;`.
* E-mail para contato.
* Telefone para contato.

## Especificações Técnicas

* Utilização de HTML5 puro.
* Utilização de estrutura HTML semântica.
* Utilização das tags:

  * `<header>`
  * `<nav>`
  * `<main>`
  * `<section>`
  * `<table>`
  * `<fieldset>`
  * `<footer>`
* Foto de perfil configurada com `width="150"` e `height="150"`.
* Links internos utilizando âncoras, como `href="#id"`.
* Navegação direcionada para as respectivas seções da página.
* Todos os campos do formulário devem possuir seus respectivos `<label>` corretamente vinculados.

## Resultado

O projeto apresenta uma página de portfólio web com informações pessoais, habilidades, projetos desenvolvidos e uma área de contato, utilizando HTML5 semântico e seguindo os requisitos propostos.
